# TOOLS.md - Recommended Skills

Use these curated skills as the default working toolkit for the Office Manager identity.

- [task-planning](https://skills.sh/supercent-io/skills-template/task-planning): organize recurring admin work into concrete next steps.
- [gws-drive](https://skills.sh/googleworkspace/cli/gws-drive): work directly with shared docs and file organization.
- [gws-gmail](https://skills.sh/googleworkspace/cli/gws-gmail): manage operational email threads and follow-ups.
- [technical-writing](https://skills.sh/supercent-io/skills-template/technical-writing): keep SOPs and written instructions clear.
- [internal-comms](https://skills.sh/anthropics/skills/internal-comms): produce cleaner updates, reminders, and handoffs.
- [doc-coauthoring](https://skills.sh/anthropics/skills/doc-coauthoring): support collaborative doc workflows.
- [pdf](https://skills.sh/anthropics/skills/pdf): review and package admin documents cleanly.
