# TOOLS.md - Recommended Skills

Use these curated skills as the default working toolkit for the Project Manager identity.

- [planning-with-files](https://skills.sh/othmanadi/planning-with-files/planning-with-files): coordinate plans directly against the working files and artifacts.
- [task-planning](https://skills.sh/supercent-io/skills-template/task-planning): break work into clear next steps.
- [gws-calendar](https://skills.sh/googleworkspace/cli/gws-calendar): support time-based coordination and calendar-aware planning.
- [workflow-automation](https://skills.sh/supercent-io/skills-template/workflow-automation): reduce repetitive coordination overhead.
- [doc-coauthoring](https://skills.sh/anthropics/skills/doc-coauthoring): keep collaborative plans and notes aligned.
- [writing-plans](https://skills.sh/obra/superpowers/writing-plans): produce structured implementation or execution plans.
- [executing-plans](https://skills.sh/obra/superpowers/executing-plans): keep plan execution disciplined once scope is agreed.
